# Syncraft Offline Workspace

Offline-first field notes and inspections using Flutter, Dart, SQLite, Go,
PostgreSQL, and WebSockets. Work is saved on the device before synchronization.
Concurrent edits remain visible until an inspector resolves them.

This repository is under active construction. See `docs/architecture.md` for
the protocol and trust boundaries. Demo data is fictional; do not use real
inspection records until deployment security and backup policies are configured.
